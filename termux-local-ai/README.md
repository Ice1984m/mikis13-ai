# Mikis13 Local AI — Termux

Lokale GGUF-modelrunner via llama.cpp. Geen betaalde AI-API
nodig. Eerste installatie en modeldownload vereisen internet.

## Gebruik

```bash
bash ~/mikis13-ai/termux-local-ai/mikis13 status
bash ~/mikis13-ai/termux-local-ai/mikis13 download
bash ~/mikis13-ai/termux-local-ai/mikis13 chat
bash ~/mikis13-ai/termux-local-ai/mikis13 models
bash ~/mikis13-ai/termux-local-ai/mikis13 test

De standaard modeldownload is ongeveer enkele gigabytes.
Vrije opslag en prestaties hangen af van het toestel.
