# Mikis13 — Oefeningen

## 1. Python
Maak een script dat een logbestand leest, fouten telt en
een rapport maakt. Voeg tests toe voor een leeg bestand.

## 2. Linux
Gebruik `pwd`, `ls -la`, `grep`, `find` en `tail` om
een eigen testmap en een voorbeeldlog te onderzoeken.

## 3. Lokale webbeveiliging
Start een eenvoudige testapp uitsluitend op localhost.
Onderzoek invoervalidatie, foutmeldingen en veilige headers.
Documenteer iedere bevinding en de oplossing.

## 4. Git
Maak een branch, wijzig een testbestand, voer tests uit
en vergelijk de wijziging met `git diff`.

## 5. Security-lab
Gebruik een bewust kwetsbare oefenapp in een geïsoleerde
omgeving. Oefen detectie, bewijs verzamelen en herstellen.
Gebruik geen echte systemen zonder toestemming.
