# Rechten bij softwarelicenties

## MIT License

Voor eigen code onder de MIT License zijn doorgaans toegestaan:

- commercieel gebruik;
- verkoop;
- wijziging;
- verspreiding;
- privégebruik.

Voorwaarde:

- de auteursrechtvermelding en licentietekst moeten behouden blijven.

## Apache License 2.0

Doorgaans toegestaan:

- commercieel gebruik;
- wijziging;
- verspreiding;
- privégebruik;
- gebruik van de expliciete patentlicentie.

Voorwaarden kunnen onder andere omvatten:

- behoud van copyright- en licentiemeldingen;
- vermelding van belangrijke wijzigingen;
- behoud van een eventueel NOTICE-bestand.

## GPLv3

Commercieel gebruik en verkoop zijn toegestaan.

Wanneer gewijzigde of afgeleide GPL-software wordt verspreid, moet doorgaans:

- de bijbehorende broncode beschikbaar zijn;
- dezelfde GPL-licentie behouden blijven;
- de licentie-informatie meegeleverd worden.

## Belangrijk

Een licentie mag alleen worden gekozen voor code waarop je zelf rechten hebt.
Een fork of gekopieerde code behoudt de licentie en voorwaarden van de
oorspronkelijke rechthebbenden.

Dit overzicht is algemene informatie en geen juridisch advies.
