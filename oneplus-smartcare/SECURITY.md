# Security policy

- No network permission is declared.
- Files are selected explicitly by the user through Android's document picker.
- Original files are read only and are never overwritten or deleted.
- Encryption uses AES/GCM/NoPadding with a fresh IV generated by Android's cryptographic provider.
- The AES key is generated in Android Keystore and is not exported by the app.
- Encrypted output is stored in the app-private files directory.
- Do not treat a hash as a malware verdict.
- Do not store passwords, API tokens, signing keys, or personal inventory reports in Git.
- Report vulnerabilities privately to the repository owner before public disclosure.
