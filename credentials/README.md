# Mikis13 certificaten en badges

Deze map bevat alleen openbare verificatiegegevens.

## Wat hier wel mag staan

- Openbare Google Developer Profile-link
- Openbare Google Skills Boost-profielpagina
- Openbare Credly-badge
- Naam van een officieel behaald certificaat
- Uitgevende organisatie
- Datum van uitgifte en eventuele vervaldatum
- SHA-256-controlesom van een lokaal bewaard document

## Wat hier niet mag staan

- Privésleutels
- API-tokens
- Wachtwoorden
- P12- of PFX-bestanden
- Clientcertificaten met privésleutel
- Niet-openbare Gmail-links
- Identiteitsdocumenten
- Zelfgemaakte of nagemaakte badges

Een vermelding in deze repository is geen bewijs zonder een officiële
verificatie-URL van de uitgevende organisatie.
